This book synthesizes the AI Freedom Trust Federation's relational-coherence, unified-reality, pattern-formation, language-audit, and consciousness-method discussions into one canonical Booksmith manuscript. The mathematical spine and philosophical distinctions were developed through iterative human-directed audits and are preserved in the chapter and appendix files rather than as workshop commentary.

The book-specific bibliography records external works used to position the manuscript in equivariant bifurcation theory, recursive geometry, and consciousness science.

The current exact derivations should be treated as canonical only to the scope stated in Appendix A. The repository still lacks a publication-grade machine-readable verification notebook, so provenance should distinguish independent reproduction of the values from artifact-level reproducibility.

The PDE-specific sixth-order center-manifold derivation remains an open source task and must not be silently filled by prose. The first sharp target is the intrinsic restricted matrix $H_{6,\mathrm{shape}}^{\mathrm{PDE}}$ on the two-dimensional quartic-flat shape plane.

Appendix G is intentionally expository rather than evidential. Descartes' Circle Theorem is cited as established mathematics; the recursive-relational state and coherence constructions are framework definitions; whole/part and scale claims are interpretive propositions. The existence of recursive circle packings is not treated as evidence that physical reality has a recursive-packing ontology.
