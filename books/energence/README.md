# Energence

**Scripture, Evolution, and the Awakening of Godself**

Energence is an active Booksmith manuscript by Zechariah Daniel Edwards. It develops a constructive panentheistic theology in conversation with Scripture, evolutionary science, information, consciousness, process theology, and resurrection.

## Canon rule

User-authored statements in `sources/author-canon.md` are accepted source material. Generated prose, citations, figures, edits, and theological reconciliations remain proposals until explicitly approved by the author.

## Production path

```text
Author canon -> chapter proposals -> source and citation audit -> figure briefs
-> LaTeX render -> proof repair -> publication gate -> publishing packet
```

## Local run

```bash
bash scripts/run-energence-termux.sh
```

The runner validates the federated library, renders deterministic LaTeX, builds the figure registry and queue, audits citations, and runs the publication pipeline as far as installed local tools allow.
