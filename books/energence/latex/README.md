# Energence LaTeX

This directory is reserved for project-specific LaTeX overrides. Deterministic source is emitted through `npm run render:latex -- energence` using Booksmith's renderer boundary.

Production profile: 6×9 nonfiction, Unicode-first XeLaTeX, editable source, BibLaTeX/Biber citations, figure provenance, glossary, index, and human-approved print assets.
