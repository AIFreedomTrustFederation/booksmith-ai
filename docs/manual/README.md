# booksmith ai UNIX Manual Manual

This directory contains the UNIX-style manual source for this repository.

The [manual manifest](../../.aift/manual.json) lists `man0` through `man9` and marks `manualSource` as `ready`, but checked-in authored sections currently exist only under `man0` and `man7`; the other categories in the [manual index](source/index.md) are reserved, not completed chapters. The manifest still marks PDF building and web publication as `planned`, so source readiness does not establish a complete, built, or published manual.

Manual source belongs to this repo. PDF and publication builds belong to BookSmith.
